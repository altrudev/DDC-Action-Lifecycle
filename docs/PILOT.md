# Design Partner / Paid Pilot Package

## Objective

Demonstrate DDC Action Lifecycle against one consequential real workflow and produce evidence that a buyer can independently review.

## Pilot scope

One action type, one integration boundary, one decision policy, one downstream consequence boundary.

Preferred first pilots:
- agentic payment / retry;
- MCP tool action;
- cloud/production change.

## Customer supplies

- workflow diagram;
- synthetic or appropriately sanitized traces;
- definition of the consequential action;
- current authorization/policy boundary;
- expected success/failure signals;
- one technical contact.

Production secrets and sensitive customer data are not required for the initial technical pilot.

## Altru.dev delivers

- action-lifecycle mapping;
- integration adapter or fixture;
- historical evidence-horizon reconstruction;
- Action Receipt / Replay linkage where applicable;
- next-transition decision demonstration;
- portable evidence bundle;
- findings report:
  - supported claims;
  - evidence gaps;
  - contradictions;
  - retry/branch behavior;
  - where proof stops;
- recommendations for production deployment.

## Acceptance criteria

A useful pilot must demonstrate all of:

1. one before-action decision reconstructed from historical evidence only;
2. one execution or dispatch boundary;
3. one later observation/consequence update;
4. later evidence does not rewrite the historical decision horizon;
5. exported evidence bundle verifies deterministically;
6. unknown/unsupported claims stay unknown;
7. the customer can identify a measurable operational value.

## Pilot commercial structure

Use fixed scope rather than unlimited consulting.

Suggested starting hypotheses to validate with buyers:
- technical design pilot: CAD 5,000–15,000;
- enterprise integration pilot: CAD 20,000–50,000+.

Do not publish these as permanent list prices until several customer conversations establish willingness to pay.

## Conversion target

A successful pilot should end in one of:
- annual DDC Action Lifecycle Runtime license;
- managed DDCAL subscription;
- private VPC deployment;
- DDC Action Gateway deployment;
- DDC Evidence Review team subscription.

## IP boundary

Customer retains its own data, workflows, credentials, and pre-existing IP.

Any pilot agreement should be reviewed professionally before use with a production customer.
